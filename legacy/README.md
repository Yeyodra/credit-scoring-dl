# Legacy — arsip versi lama

Folder ini berisi versi **lengkap/lama** proyek sebagai arsip. **Tidak dipakai**
oleh versi ringkas di root repo.

Isi:
- `src/` — kode versi lama (embedding kategorikal, ekspor bobot NumPy,
  `server.py` tanpa PyTorch, berbagai skrip uji: parity/render/online).
- `docs/` — laporan & panduan lama (LAPORAN.md, CHEAT_SHEET.md, DEPLOYMENT.md + PDF).
- `artifacts/` — model & metrik versi lama (AUC 0,7730).
- `md_to_pdf.py`, `README.md` — skrip konversi & README lama.

Versi aktif (ringkas) ada di root: `model.py`, `train.py`, `app.py`,
`templates/`, `artifacts/`.
